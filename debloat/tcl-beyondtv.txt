# Packages disabled on a TCL BeyondTV (Android TV 9). One per line; '#' starts a comment.
# Used by tools/debloat.sh. Each is disabled with `pm disable-user --user 0` (never uninstalled)
# and logged to backup/disabled_by_us.txt so tools/restore.sh can undo it.
# Check each package on your own TV first: tools/tv shell 'dumpsys package <pkg>'

# * This firmware re-enables these at every boot (updated system apps it re-scans).

# Kept on purpose: com.tcl.tv / com.tcl.tvinput (Live TV, HDMI, source menu), remote/Bluetooth

# (com.google.android.apps.mediashell), Miracast, and all streaming apps.
# The stock launcher (com.google.android.tvlauncher) is disabled by tools/build_install.sh,
# only after Glass Home is installed.
